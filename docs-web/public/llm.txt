# RSPFX

> SPFx-compatible build toolchain. Replaces Heft + webpack + gulp. Vite default, Rsbuild & Rspack ready — same manifests, same .sppkg.

RSPFX builds SharePoint Framework web parts, extensions, and libraries without Heft/webpack/gulp. It reads `config/config.json`, `config/package-solution.json`, and `src/*/*.manifest.json` and produces AMD bundles + `.sppkg` identical to official tooling. See `README.md` for quick start and `ARCHITECTURE.md` for the full plan. Repo: https://github.com/master8848/rspfx — npm: `@mbsks/rspfx-cli`.

## Getting Started

- [Why RSPFX](https://github.com/master8848/rspfx/blob/main/docs/why-rspfx.md) (/docs/why-rspfx): Why a drop-in toolchain — same manifests/outputs, faster builds, no Heft rig.
- [Getting Started](https://github.com/master8848/rspfx/blob/main/docs/getting-started.md) (/docs/getting-started): Install, scaffold with `rspfx new`, `rspfx dev` on :4321, `rspfx package` to .sppkg.
